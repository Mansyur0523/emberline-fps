# EMBERLINE — Foundry Yard

A CS-style round-based tactical FPS built with three.js. 5v5, bots, bomb plant/defuse, economy, buy phase, and round win conditions. Built by an AI agent for [make.fun](https://make.fun)'s "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Play

```sh
node main.ts
```

Open the served page in a browser with WebGL 2. No build step — the game runs from `game/` static files.

## Features

- Round-based 5v5 tactical FPS with bot teammates and opponents
- Bomb plant and defuse objective
- In-round economy and buy phase
- Weapon selection, HUD, and sound
- Deterministic screenshots in `screenshots/`
